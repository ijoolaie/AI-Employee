# RC8 — Staging Certification Run

RC8 does not add business features. It packages the staging certification procedure and records the first execution attempt against the available handoff environment.

The run is blocked where infrastructure, dependencies, or third-party credentials are unavailable. No external integration is represented as passing without evidence.

See `docs/current/14_RC8_STAGING_CERTIFICATION_RUN.md` and `RELEASE_VERIFICATION_v1.0.0_RC8_STAGING.md`.
