# Releases

Release records live here. Each release should identify:

- version/tag
- source commit
- scope
- automated verification
- known limitations
- production/external evidence status
- certification decision

A release being buildable or CI-green does not automatically make it production-certified.

Historical certification records should remain traceable and should not be silently rewritten.

For the current overall status, see [Current Status](../current/STATUS.md).
