## Required evidence boundary

The production-like certification workflow is deterministic: it accepts an exact `target_sha`, checks out that SHA, asserts the checked-out commit equals the requested SHA, and executes backend, migration, frontend, OCR, product-gate and Playwright validation against that checkout.

Production deployment, live provider validation, measured production SLO/DR, independent security review and customer acceptance remain separate external boundaries.

`v1.3.8` remains immutable and continues to be the last certified release until a new exact-SHA candidate is independently certified.
