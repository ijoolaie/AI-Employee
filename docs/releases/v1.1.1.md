# AI Employee v1.1.1 — Delivery Hardening Patch

## Release position

`v1.1.1` is a patch release following the immutable vendor release `v1.1.0`.

It does not replace or mutate `v1.1.0`. It records the delivery, migration, CI, and documentation hardening completed after `v1.1.0`.

## Included

- Merge Alembic migration heads so `alembic upgrade head` has a single target.
- Align vendor, reseller, and customer delivery manifests with immutable vendor release `v1.1.0`.
- Harden delivery manifest validation and packaging identity checks.
- Correct production deployment workflow environment scoping.
- Align production status documentation with the v1.1 delivery architecture.
- Preserve `v1.0.1` only as a historical rollback reference.

## Validation

- Architecture Guard: passed on the release hardening PRs.
- Production Compose Validation: passed on the release hardening PRs.
- Delivery Manifest Bundle: passed after merge on `main` (`d306ce6`).
- Production Target Deployment: deferred because production target secrets are not yet configured.

## Delivery model

Vendor Core → Reseller Edition → End Customer Deployment

Reseller and customer deliveries reference the immutable vendor release and their own configuration, entitlement, and deployment revisions. They are not permanent source forks.

## Release boundary

- Base vendor release: `v1.1.0`
- Release branch: `release/v1.1.1`
- Current main revision at preparation: `d306ce6`
- Production deployment remains a deferred operational gate until production secrets are provisioned.
