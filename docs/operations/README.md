# Operations

Operational documentation belongs here.

## Areas

- Deployment and environment configuration
- Production compose validation
- Secrets and configuration hardening
- Health checks and observability
- Backup and restore
- Rollback and recovery
- Dead-letter/recovery operations
- Production evidence collection

## Important distinction

A workflow, script, or compose file proves that operational tooling exists. It does not by itself prove that a real production operation succeeded. Production claims require environment-specific evidence.
