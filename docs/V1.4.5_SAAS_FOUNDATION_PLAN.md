# Lifecycle Requirements

Tenant lifecycle must explicitly support, as applicable:

```text
provisioned -> active -> suspended -> active
                         |
                         +-> archived -> retained/deleted by policy
```

Execution resources must explicitly support terminal outcomes such as success, failure and cancellation. Stop/Cancel must affect the real backend operation, not only the displayed status.

Hard deletion is not the default tenant operation. Retention and reactivation behavior must be defined before destructive tenant deletion is exposed.
