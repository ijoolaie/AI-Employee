# AI Employee v1.3.1 Database Schema Plan

## Objective
Prepare the persistence foundation for SaaS multi-tenancy.

## Core Entities

### tenants
- id
- name
- status
- plan_id
- created_at

### users
- id
- tenant_id
- email
- role
- status

### subscriptions
- id
- tenant_id
- plan
- billing_cycle
- limits

### usage_records
- id
- tenant_id
- metric
- amount
- period

### api_keys
- id
- tenant_id
- key_hash
- scope
- expires_at

## Migration Strategy
1. Add SaaS tables without breaking existing production.
2. Introduce tenant_id gradually.
3. Backfill existing records.
4. Enable tenant enforcement.

## Success Criteria
- Zero data leakage between tenants.
- Auditable usage tracking.
- Subscription-ready architecture.
