# AI Employee v1.3.1 Multi Tenant Database Design

## Core Entities

### Tenant
Represents an isolated SaaS customer workspace.

Fields:
- id
- name
- status
- plan_id
- created_at

### User
Represents platform users.

Fields:
- id
- tenant_id
- email
- role
- status

### Employee Agent
Represents AI employees owned by tenants.

Fields:
- id
- tenant_id
- template_id
- configuration

### Usage Records
Tracks SaaS consumption.

Fields:
- id
- tenant_id
- metric
- quantity
- timestamp

## Isolation Rules

Every business entity must include tenant_id.

Queries must enforce tenant scope.

No cross tenant access is allowed.

## Migration Strategy

1. Introduce tenant tables
2. Add tenant_id columns
3. Backfill existing production data
4. Enable isolation policies
5. Validate with automated tests
