# sharp 0.35.4 remediation

The frontend currently uses Next.js 16.3.4. The previous explicit override forced sharp 0.35.3, which is vulnerable. The override has been removed so Next.js can resolve its declared sharp dependency at the patched 0.35.4 line. The committed npm lockfile must be regenerated by npm before merge; CI uses `npm ci` and therefore must validate the resulting lockfile.
