# How to Navigate Documentation

## Start here

Use this directory for current orientation.

## Canonical areas

- docs/current — active status, active plans and reconciliations.
- docs/architecture — architecture source documents.
- docs/operations — deployment and operational procedures.
- docs/releases — immutable release/certification records.
- docs/evidence — verification and production evidence.
- docs/archive — historical records.
- docs/00_START_HERE — entry point and current orientation.

## Classification

Every document should be one of:

- CURRENT
- CANONICAL
- HISTORICAL
- SUPERSEDED
- EVIDENCE
- TEMPLATE

Historical evidence is preserved; current implementation must not rely on superseded guidance.

## Change rule

Any PR changing architecture, product phase or release truth must update the relevant current-status or canonical document.
