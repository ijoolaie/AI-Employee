# Project Overview

AI Employee Platform is a multi-tenant operating platform for Platform/Vendor, Reseller and Client organizations.

The product is evolving toward a Human + Agent Operating System:

- work is represented as a shared business contract;
- specialized Agents and Humans can execute work;
- execution may be delegated or collaborative;
- permissions, approvals, tools, audit and cost controls apply to all executors;
- Platform, Reseller and Client remain separate control planes.

Current certified product release: v1.2.0.
Current architecture baseline: V1.4 frozen baseline.
Next architecture extension: V1.5 Agentic Operating Model.
