# Phase 4 Delivery Acceptance Gate

Phase 4 is complete only when every gate below is evidenced.

- [ ] 4A release artifact generated and checksum verified
- [ ] 4B customer configuration template generated and compose interpolation validated
- [ ] 4C installation runbook executed on a clean environment
- [ ] 4D upgrade/migration runbook executed on a representative environment
- [ ] 4E backup and restore demonstrated
- [ ] 4F rollback demonstrated against a known-good release
- [ ] 4G customer acceptance checklist signed
- [ ] 4H security/secrets checklist passed
- [ ] 4I compatibility matrix checked against the deployment environment
- [ ] 4J vendor/reseller/customer handoff record completed

Evidence must include release version, source commit, checksum, migration head, environment/runtime versions, backup/restore references, operator and test date. A documented design is not equivalent to executed evidence.
