## Release context

`v1.4.4` is the current stable release baseline. This contract defines the API evolution required for `v1.4.5`.

## Customer API

### Employee Management
- Create AI Employee
- Update configuration
- View status
- Lifecycle actions where applicable

### Knowledge API
- Upload documents
- Index knowledge
- Query memory

## Developer Console API

- Create API keys
- Manage scopes
- Monitor usage
- Refresh/re-fetch current state

## SaaS Platform API

- Vendor provisioning of Reseller tenants
- Reseller provisioning of Client tenants
- Tenant hierarchy/context
- Plan and entitlement management
- Subscription status
- Usage and quota status
- Tenant onboarding/offboarding
- Suspension/reactivation
- Billing events

## Resource Lifecycle API

Applicable resources expose idempotent lifecycle actions such as:

- start
- stop/cancel
- archive
- delete where hard deletion is safe
- restore/reactivate where supported

Lifecycle actions must validate authorization and current resource state and must create audit records for administrative/destructive transitions.

## Security

All APIs require:

- Authentication
- Explicit tenant context
- Server-side tenant isolation
- RBAC/authorization validation
- Plan/entitlement validation where applicable
- Audit logging for sensitive actions

Client-provided tenant identifiers are never sufficient authorization evidence.
